# Flask Image Captioner

A simple Flask web application that allows users to upload an image (JPEG/PNG) and receive a natural‐language caption generated by a pretrained BLIP model (Salesforce/blip-image-captioning-base). The app is styled with custom CSS, supports client‐side image preview, and can be easily containerized with Docker.

## Features

- **Image Upload**  
  • Users can upload a JPG/PNG image from their computer.  
  • Client‐side preview shows the selected image before upload.  

- **AI-Generated Caption**  
  • Backend uses Hugging Face’s BLIP (“Salesforce/blip-image-captioning-base”) to generate a human‐readable caption.  
  • Caption appears below the image in a styled result box.  

- **Error Handling**  
  • Rejects non-image files with a user-friendly flash message.  
  • Catches server-side exceptions and displays an error banner.  

- **Responsive UI**  
  • Custom CSS ensures the form, buttons, and result box look clean on desktop and mobile.  

- **Optional Fine-Tuning**  
  • Includes instructions and script to fine-tune the pretrained BLIP model on your own (image, caption) dataset.  

- **Docker Support**  
  • Dockerfile pre-downloads model weights at build time to reduce cold-start latency.  
  • One-step `docker build` and `docker run` commands to get a containerized version.
